    How the engine ran it

    Run a query to see its operator tree. Each box is an operator that pulls rows from the ones below it; the number is how many rows it produced.

    Each box is one 4 KB page. Internal pages hold separator keys and point down; leaf pages hold the keys with row ids and are chained left to right for range scans.

    Each square is one 4 KB slotted page of the table's file. Darker means fuller. Hover a page to see its slots and free bytes.

    Buffer pool

    Every table and index file has its own pool of in-memory frames. A hit means the page was already cached; a miss means it was read from disk.
